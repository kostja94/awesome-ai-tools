## Models

<a id="section-language-models"></a>

### Language & Search Models

Model selection starts with [general-purpose LLM capabilities and evaluation trade-offs](https://alignify.co/tools/llm).

- <a href="https://openai.com/" target="_blank">GPT</a> - OpenAI's flagship large language model family (GPT-4/4.5/5/6 series and variants).
- <a href="https://gemini.google.com/" target="_blank">Gemini</a> - Google DeepMind's multimodal large model supporting text, image, audio, and video inputs, with releases spanning the 2.5, 3 and 4 series.
- <a href="https://claude.com/" target="_blank">Claude</a> - Large language model family developed by Anthropic, offered via API and in Claude assistant products.
- <a href="https://x.ai/" target="_blank">Grok</a> - Large language model family from xAI, spanning Grok 3, Grok 4 and Grok 4.1, that powers the Grok assistant on X and grok.com and is offered through the xAI API.
- <a href="https://dev.meta.ai/" target="_blank">Llama</a> - Meta's open-weight language model series, from Llama 3 through Llama 4.
- <a href="https://www.deepseek.com/" target="_blank">DeepSeek</a> - DeepSeek's open-weight language model family across V2, V3, V3.1, V4 Pro and R1 releases.
- <a href="https://chat.qwen.ai/" target="_blank">Qwen</a> - Alibaba's open-weight language model family, from Qwen2.5 through Qwen3.7.
- <a href="https://mistral.ai/" target="_blank">Mistral</a> - Mistral AI's general-purpose large language model family, organized in Small, Medium and Large tiers such as Mistral Large 2 and Mistral Medium 3, offered via la Plateforme API and enterprise deployments.
- <a href="https://deepmind.google/models/gemma/" target="_blank">Gemma</a> - Gemma is a family of open-weight models from Google built using research and technology from the Gemini model program, spanning Gemma 1 through Gemma 4.
- <a href="https://www.kimi.com/" target="_blank">Kimi</a> - Moonshot AI's language model family for text, code and reasoning tasks, including vision-capable and open-weight releases from K1.5 through K3.
- <a href="https://docs.z.ai/" target="_blank">GLM</a> - Large language model family from Zhipu AI (Z.ai), spanning GLM-4, GLM-4.5 and GLM-5, offered via the Z.ai API with open-weight releases under the MIT license since 2025.
- <a href="https://hunyuan.tencent.com/" target="_blank">Hunyuan</a> - Hunyuan is Tencent's family of AI models spanning language, image, video and three-dimensional content generation.
- <a href="https://www.minimax.io/" target="_blank">MiniMax</a> - MiniMax's language model family with open weights, covering text generation, coding and tool-assisted workflows; current release M2.7.
- <a href="https://github.com/QwenLM/Qwen3-Coder" target="_blank">Qwen Coder</a> - Alibaba's specialized coding model family under the Apache 2.0 license, spanning Qwen2.5-Coder, Qwen3-Coder and Qwen3-Coder-Next.
- <a href="https://aleph-alpha.com" target="_blank">Luminous</a> - Language model family from Aleph Alpha, supporting multilingual text and image analysis.

<a id="section-image-models"></a>

### Image Models

- <a href="https://www.midjourney.com/" target="_blank">Midjourney</a> - Independent lab Midjourney's text-to-image and video model family known for its artistic style, with image models up to V8; served through its website and Discord.
- <a href="https://developers.openai.com/api/docs/models/gpt-image-2" target="_blank">GPT Image</a> - OpenAI image generation and editing family; the current gpt-image-2.5 (ChatGPT Images 2.5) generates and edits images from prompts, sketches and reference photos with multilingual in-image text, available in ChatGPT and the API.
- <a href="https://aistudio.google.com/models/nano-banana" target="_blank">Nano Banana</a> - Google image generation and editing family; the current Nano Banana 2.1 is a high-efficiency generation and conversational-editing model superseding Nano Banana 2 (Gemini 3.1 Flash Image), offered through Gemini apps, AI Studio and the Gemini API.
- <a href="https://www.adobe.com/products/firefly.html" target="_blank">Adobe Firefly</a> - Adobe's text-to-image generation model integrated with Creative Cloud
- <a href="https://stability.ai/" target="_blank">Stable Diffusion</a> - Open-source text-to-image models with API access
- <a href="https://bfl.ai/" target="_blank">FLUX</a> - Black Forest Labs' text-to-image generation model
- <a href="https://seed.bytedance.com/en/tech/seedream3_0" target="_blank">Seedream</a> - ByteDance Seed image model family; Seedream 4.0 unifies generation and editing with multi-image inputs up to 4K.
- <a href="https://ideogram.ai/" target="_blank">Ideogram</a> - Text-to-image generation model with a focus on text rendering.
- <a href="https://chat.qwen.ai" target="_blank">Qwen Image</a> - Alibaba Qwen image-generation family spanning Qwen-Image-2.0 and the current Qwen-Image-3.0, which adds long-prompt comprehension and legible Chinese-English text in images; served via DashScope and Qwen Chat, with open-weight base releases.
- <a href="https://hunyuan.tencent.com/image/en" target="_blank">Tencent Hunyuan Image</a> - Tencent Hunyuan image-generation family; HunyuanImage-3.0 is an open-weight native-multimodal model with strong in-image text rendering, and the Hy Image 3.5 preview adds multi-round conversational editing with reference images, served via Hunyuan and Tencent Cloud.
- <a href="https://www.recraft.ai/" target="_blank">Recraft</a> - Text-to-image generation model supporting vectors and mockups
- <a href="https://www.microsoft.com/en-us/ai/mai-image" target="_blank">MAI Image</a> - Microsoft AI's text-to-image generation model
- <a href="https://lumalabs.ai/photon" target="_blank">Luma Photon</a> - Luma Labs' text-to-image models, served via its API as photon-1 and photon-flash-1 with up to 4 reference images.
- <a href="https://hidreamai.com/" target="_blank">HiDream</a> - Omni-modal foundation models from Beijing-based HiDream covering image, video and 3D, with open-source HiDream-E1.1 for editing.
- <a href="https://reve.com/" target="_blank">Reve</a> - Text-to-image model with a web app unifying creation, editing and remixing via natural-language and drag-and-drop editing.

<a id="section-video-models"></a>

### Video Models

- <a href="https://deepmind.google/technologies/veo/" target="_blank">Google Veo</a> - Google text-to-video generation model family; the current Veo 3.1 outputs video with native audio at up to 4K resolution with SynthID watermarking, served through Gemini apps and API.
- <a href="https://kling.ai/" target="_blank">Kling</a> - Kuaishou's AI video and image platform; its video model line has reached Kling 4.0, and Kling Image 3.0 outputs native 4K.
- <a href="https://runway.com/" target="_blank">Runway Gen</a> - Runway's video model family led by Gen-4.5, with the GWM-1 general world model alongside, served via its web app and API.
- <a href="https://seed.bytedance.com/en/seedance" target="_blank">Seedance</a> - Video generation model family from ByteDance's Seed team; versions span Seedance 1.0 (2025) through 2.0 to the current 2.5 (2026-07), generating synchronized audio at up to 2K resolution from text, image and multi-reference inputs, with 2.5 adding reference control, editing and extendable 30-second clips; also served through the Dreamina platform.
- <a href="https://lumalabs.ai/ray" target="_blank">Luma Ray</a> - Luma's Ray model family for text-, image- and video-conditioned video generation and editing.
- <a href="https://pika.art/" target="_blank">Pika</a> - Pika Labs' text-to-video model family; Pika 2.2 outputs 1080p clips up to 10 seconds with Pikaframes and Pikaffects features.
- <a href="https://tongyi.aliyun.com/wanxiang/" target="_blank">WAN</a> - Alibaba's Wan model family for text- and image-conditioned video generation.
- <a href="https://aivideo.hunyuan.tencent.com/" target="_blank">Tencent Hunyuan Video</a> - Tencent's video generation model family, producing video from both text and image inputs.
- <a href="https://www.vidu.com/" target="_blank">Vidu</a> - Video generation family from Shengshu Technology, spanning text-to-video, image-to-video and multi-reference video generation.
- <a href="https://www.genmo.ai/" target="_blank">Mochi</a> - Genmo's open text-to-video model; Mochi 1 preview weights are on Hugging Face with GitHub code and local ComfyUI support.
- <a href="https://www.animon.ai/" target="_blank">Animon</a> - Anime-specific AI video generator from Tokyo-based Animon, launched April 2025 with unlimited generation on subscriptions.

<a id="section-speech-models"></a>

### Speech Models

- <a href="https://github.com/openai/whisper" target="_blank">OpenAI Whisper</a> - Open-source speech recognition model from OpenAI covering 99 languages and deployable locally; community derivatives include WhisperX and faster-whisper.
- <a href="https://elevenlabs.io/speech-to-text" target="_blank">ElevenLabs Scribe</a> - Speech-to-text model family from ElevenLabs spanning batch, real-time streaming and Medical variants across 90+ languages, built for voice-agent and transcription workloads.
- <a href="https://docs.cloud.google.com/speech-to-text/docs/models/chirp-3" target="_blank">Google Chirp</a> - Speech-to-text model family in Google Cloud Speech-to-Text; the current Chirp 3 supports 100+ languages on a Conformer architecture.
- <a href="https://deepgram.com/" target="_blank">Deepgram Nova</a> - Speech recognition model that transcribes 142 seconds of audio per second.
- <a href="https://www.sesame.com/" target="_blank">Sesame CSM</a> - Conversational speech model from Sesame released under Apache 2.0; the open CSM-1B release accompanies a larger model demonstrated in the company voice demos.
- <a href="https://www.cartesia.ai/sonic" target="_blank">Sonic</a> - Cartesia family of streaming text-to-speech models for spoken output in real-time applications.
- <a href="https://dev.hume.ai/voice/docs/text-to-speech-tts/overview" target="_blank">Octave</a> - Hume speech-language model family for expressive text-to-speech generation.
- <a href="https://fish.audio" target="_blank">Fish Audio S2</a> - Production text-to-speech line from Fish Audio spanning S2 Pro and the current S2.1 Pro, covering 83 languages with inline bracket-tag control of prosody and emotion.
- <a href="https://inworld.ai/" target="_blank">Inworld TTS</a> - Real-time text-to-speech model with multilingual support.
- <a href="https://www.zyphra.com/models/zonos2" target="_blank">ZONOS</a> - Zyphra family of speech generation models with voice cloning and real-time text-to-speech variants.

### 3D & Spatial Models

- <a href="https://3d.hunyuan.tencent.com/" target="_blank">Hunyuan3D</a> - Generates realistic 3D models with clean geometric structure from text and images, particularly for character generation.

## Agent Development Infrastructure

<a id="section-agent-platforms"></a>

### Agent Frameworks & Infrastructure

- <a href="https://www.langchain.com/langgraph" target="_blank">LangGraph</a> - Open-source framework from the LangChain team for building stateful, multi-actor agent applications as graphs, with checkpointing, cycles and human-in-the-loop control.
- <a href="https://crewai.com" target="_blank">CrewAI</a> - Open-source framework and hosted platform for orchestrating role-based multi-agent workflows in Python.
- <a href="https://www.langchain.com/langsmith-platform" target="_blank">LangSmith</a> - LangChain's platform for tracing, debugging, evaluating and monitoring LLM agents, with cost and latency tracking, datasets and regression detection.
- <a href="https://platform.claude.com/docs/en/agents-and-tools/tool-use/computer-use-tool" target="_blank">Anthropic Computer Use</a> - Claude tool and reference implementation that lets AI agents interpret screenshots and control a computer's mouse and keyboard through the API.
- <a href="https://labs.google.com/mariner/landing" target="_blank">Google Project Mariner</a> - Google DeepMind research agent that operates a Chrome browser to complete multi-step web tasks, offered as an early experiment.
- <a href="https://www.openinterpreter.com" target="_blank">Open Interpreter</a> - Open-source coding agent that lets language models run code on a user's computer; developed as a fork of OpenAI's Codex focused on low-cost, open-weight models.
- <a href="https://langfuse.com" target="_blank">Langfuse</a> - Open-source LLM engineering platform for tracing, prompt management, evaluations and analytics, self-hostable or available as a cloud service; acquired by ClickHouse.
- <a href="https://huggingface.co/docs/smolagents" target="_blank">Smolagents</a> - Minimalist open-source agent library from Hugging Face whose CodeAgent writes actions as Python code, working with any language model.
- <a href="https://ag2.ai" target="_blank">AG2</a> - Open-source multi-agent framework from the AutoGen team for building and orchestrating systems of cooperating AI agents.
- <a href="https://www.camel-ai.org" target="_blank">CAMEL-AI</a> - Open-source multi-agent framework for building and studying LLM-powered agent applications, including role-playing agent societies and tool use.
- <a href="https://mem0.ai/" target="_blank">Mem0</a> - Memory layer for AI agents with automatic extraction, cleaning and storage over a hybrid vector and knowledge-graph architecture; offered as a managed platform and as open source for self-hosting.
- <a href="https://www.letta.com" target="_blank">Letta</a> - Open-source platform for stateful AI agents with persistent memory, formerly known as MemGPT, keeping context, identity and learned behavior across sessions.
- <a href="https://livekit.com/" target="_blank">LiveKit</a> - Real-time communication infrastructure for building voice and video applications
- <a href="https://openfga.dev" target="_blank">OpenFGA</a> - Open-source fine-grained authorization engine modeled on Google Zanzibar, providing relationship-based access control for applications and AI agent systems.
- <a href="https://composio.dev" target="_blank">Composio</a> - Integration platform for AI agents providing managed authentication, tool execution and triggers across a large catalog of third-party applications, with sandboxed execution and framework-agnostic SDKs.
- <a href="https://www.getzep.com/" target="_blank">Zep</a> - Managed memory and context service for AI agents and assistants; its companion open-source project Graphiti provides the temporal knowledge graph layer.
- <a href="https://agentops.ai" target="_blank">AgentOps</a> - Developer platform for AI agent observability, offering SDK-based session tracing, debugging, replay, and cost monitoring across frameworks.
- <a href="https://www.comet.com/site/products/opik" target="_blank">Opik</a> - Open-source platform from Comet for tracing, evaluating and monitoring LLM and AI agent applications in development and production.
- <a href="https://trigger.dev" target="_blank">Trigger.dev</a> - Open-source TypeScript framework and cloud platform for durable background workflows and AI agent orchestration, with retries, state management and observability.
- <a href="https://hatchet.run" target="_blank">Hatchet</a> - Workflow orchestration and task queue platform for AI agents and background jobs, with durable execution, retries, scheduling and concurrency controls; MIT-licensed and self-hostable, with a managed cloud.
- <a href="https://riza.io" target="_blank">Riza</a> - Sandbox runtime that executes untrusted code generated by AI applications inside isolated WebAssembly environments, via an API.
- <a href="https://notte.cc" target="_blank">Notte</a> - Browser platform for AI agents offering managed cloud browser sessions with persistent identities, a login vault and page extraction optimized for language models.
- <a href="https://lavague.ai" target="_blank">LaVague</a> - Open-source Large Action Model framework for building web agents that turn natural language into browser automation code with Selenium or Playwright.
- <a href="https://www.useparagon.com" target="_blank">Paragon</a> - Integration platform for AI agents and software products that manages connections to third-party applications and lets agents use external tools.
- <a href="https://toolhouse.ai" target="_blank">Toolhouse</a> - Platform for building and running AI agents and always-on AI workers that connect to thousands of external services and escalate exceptions for human review.
- <a href="https://supermemory.ai" target="_blank">Supermemory</a> - Memory infrastructure for AI applications providing a knowledge-graph based persistent memory layer and APIs; open-source (MIT), with a managed API, MCP server and an end-user memory app.
- <a href="https://www.cognee.ai/" target="_blank">Cognee</a> - Open-source AI memory engine that transforms raw data into persistent and dynamic AI memory for agents; combines vector search with knowledge graphs; ECL (Extract, Cognify, Link) framework
- <a href="https://github.com/MemTensor/MemOS" target="_blank">MemOS</a> - Open-source memory operating system for LLM agents unifying plaintext, activation/KV-cache and parametric memory through MemCube abstractions, with lifecycle scheduling, governance and multi-agent sharing.
- <a href="https://langchain-ai.github.io/langmem/" target="_blank">LangMem</a> - Open-source memory utilities for LangGraph from the LangChain team, providing fact extraction, consolidation, update and deletion with hot-path tools and a background manager.
- <a href="https://github.com/memodb-io/memobase" target="_blank">Memobase</a> - Profile-based long-term memory system for AI applications, handling user profiles, memory events and evolving context; suited to chatbots, companions and user-centric apps.
- <a href="https://github.com/NevaMind-AI/memU" target="_blank">memU</a> - Open-source memory sidecar for agents that turns desktop and coding-agent histories into reusable wiki pages, memories and skills, with multi-host adapters.
- <a href="https://github.com/EverMind-AI/EverOS" target="_blank">EverOS</a> - Portable local-first memory layer for AI agents with Markdown-native, user-owned storage.
- <a href="https://mirix.io/" target="_blank">Mirix</a> - Screen-level multimodal memory system that monitors the screen in real time, capturing screen, behavior and events into a personalized memory base with reduced storage needs.
- <a href="https://memories.ai" target="_blank">Memories.ai</a> - Platform offering video intelligence APIs that index visual data into searchable memory for AI agents, based on a large visual memory model.
- <a href="https://verodat.com" target="_blank">Verodat</a> - Data governance platform that supplies validated, lineage-tracked and context-enriched data for AI agents, analytics and automation.
- <a href="https://turbomcp.ai/" target="_blank">Turbo MCP</a> - Self-hosted Model Context Protocol gateway and management platform by Dylibso; evolved from MCP.run, which ran MCP tools in sandboxed WebAssembly.
- <a href="https://promptql.io" target="_blank">PromptQL</a> - Agentic data access layer from the team behind Hasura that lets AI agents generate and run query plans across connected databases and APIs.
- <a href="https://anon.com" target="_blank">Anon</a> - Developer toolkit that lets AI agents authenticate and perform actions on behalf of users across websites that lack official APIs.
- <a href="https://gensx.com" target="_blank">GenSX</a> - Open-source TypeScript framework for building AI agents and multi-step workflows as composable components.
- <a href="https://praison.ai" target="_blank">Praison AI</a> - Open-source low-code framework for building, managing and deploying multi-agent LLM applications.
- <a href="https://agentstack.sh" target="_blank">AgentStack</a> - Open-source framework and CLI for scaffolding multi-agent LLM applications with tool integrations.
- <a href="https://www.swarms.ai" target="_blank">Swarms.ai</a> - Multi-agent framework and hosted platform for building, deploying and scaling AI agents in Python and Rust, with an agent marketplace.
- <a href="https://raygun.com" target="_blank">Raygun</a> - Error tracking, crash reporting and application performance monitoring software for development teams.
- <a href="https://metoro.io" target="_blank">Metoro</a> - AI SRE and observability platform for Kubernetes that detects production issues and investigates alerts using eBPF-based telemetry.
- <a href="https://gradial.com" target="_blank">Gradial</a> - Enterprise platform that uses AI agents to automate marketing operations such as campaign assembly, content authoring, QA and brand checks.
- <a href="https://www.dropzone.ai" target="_blank">Dropzone AI</a> - Platform of AI agents for security operations that autonomously investigate alerts and hunt threats in SOC workflows.
- <a href="https://www.tinyfish.ai/" target="_blank">Tiny Fish</a> - Web infrastructure for AI agents: live search, URL extraction, cloud browsers and plain-English automation under a single API.
- <a href="https://osatlas.github.io" target="_blank">OS-Atlas</a> - Open-source foundation action model for GUI grounding, trained on a large cross-platform dataset of interface elements for generalist GUI agents.
- <a href="https://fireproof.storage" target="_blank">Fireproof</a> - Open-source embedded JavaScript database with a verifiable ledger structure, browser-side storage, and encrypted sync, used for agent and local-first apps.
- <a href="https://www.bytebot.ai" target="_blank">Bytebot</a> - Open-source browser automation agent framework (Apache-2.0, repository archived).

<a id="section-agent-payments-identity"></a>

### Agent Payments & Identity

- <a href="https://docs.stripe.com/agents" target="_blank">Stripe Agent SDK</a> - Stripe toolkit that lets AI agents initiate payments, manage carts and checkout and use Link credentials; integrates with agent frameworks such as LangChain and the Vercel AI SDK.
- <a href="https://auth0.com" target="_blank">Auth0</a> - Authentication and authorization platform for web and mobile applications, including identity and access controls for AI agents.
- <a href="https://clerk.com" target="_blank">Clerk</a> - Authentication and user-management platform for developers offering embeddable UI components, APIs, organization (B2B) support, session management and billing integration.
- <a href="https://skyfire.xyz/" target="_blank">Skyfire</a> - Financial infrastructure for the AI economy, supporting autonomous payments and identity verification for AI agents
- <a href="https://paymanai.com/" target="_blank">Payman</a> - AI payment agents for banks and credit unions, running payments, transfers and account analysis under SOC 2 Type II controls.
- <a href="https://nekuda.ai/" target="_blank">Nekuda</a> - Building secure and compliant payment gateways for AI agents, enabling automated payments on a user's behalf and credential management.
- <a href="https://www.authing.com/" target="_blank">Authing</a> - Enterprise identity cloud (IDaaS), implementing unified login, authorization, and multi-tenant management through SDK/API
- <a href="https://protegee.ai" target="_blank">Protegee AI</a> - Startup building payment infrastructure for AI agents; the public site is limited to a login page.

<a id="section-agent-evaluation"></a>

### Agent & Model Evaluation

[Model and application evaluation workflows](https://alignify.co/tools/evaluation) provide context for choosing benchmarks and testing tools.
